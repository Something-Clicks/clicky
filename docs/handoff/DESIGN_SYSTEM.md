# Design System

## Brand feel
Friendly, playful, inviting, clever, calm, and capable. The product should feel easy to work with. Keep the interface clean and trustworthy, with personality in Clicky, microcopy, illustrations, and small moments of delight.

## Working colors
- Cobalt blue: `#3977D5` — primary actions and navigation accents.
- Warm emoji yellow: `#FFC928` — Clicky mascot signature color.
- Coral: `#FF897C` — sparing accent.
- Mint: `#75DDB5` — positive progress accents.
- Dark navy: `#252A35` — text and facial features.
- Soft cream: `#FFF9EF` — optional warm surface.
- White: `#FFFFFF` — main surfaces.
Use accessible contrast; semantic success/warning/error colors must remain distinguishable and not rely on color alone.

## Type and layout
Use the existing project typography if suitable; otherwise use a clean sans-serif such as Inter. Clear type scale, generous whitespace, readable line lengths, responsive grid, consistent spacing, subtle borders, soft shadows, rounded cards and controls. Avoid clutter and excessive gradients.

## Components
- Buttons: one clear primary action per view; secondary actions visually quieter.
- Action Cards: title, impact/priority, plain-language reason, evidence, recommended next step, AI/approval status, action button, status.
- Status chips: New, Needs approval, In progress, Done, Failed; text labels always visible.
- Empty states: explain why the area is empty and give one useful next action; Clicky may appear as a small supportive accent.
- Loading states: explain what is happening; avoid fake progress percentages.
- Errors: say what happened and what the user can do next.
- Forms: progressive disclosure, minimal fields, inline validation, clear privacy context.

## Copy
Short, direct, benefit-first. Avoid jargon such as “synergy,” “leverage,” “growth hacking,” or unexplained SEO terminology. Explain technical findings in plain language. Avoid promises of rankings, calls, leads, revenue, or guaranteed outcomes.

## Motion
Use subtle, purposeful transitions only. Respect reduced-motion preferences. Clicky can animate briefly for a completed task or helpful onboarding moment, never as constant decoration.

## Accessibility and responsive behavior
Target WCAG 2.2 AA where practical. Keyboard navigation, visible focus, semantic headings, labels, accessible dialogs, contrast, reduced motion, responsive layouts, and touch-friendly controls. Test mobile, tablet, and desktop.
