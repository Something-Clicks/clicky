# Acceptance criteria: when the Something Clicks Marketing Agent is "finished"

Written Nov 27 2026 at the owner's request. Source of truth for scope: the owner's specification (`AI_MARKETING_AGENT.docx`, sections 1-19) and `MARKETING_AGENT.md`. Thresholds for model quality are **not** restated or changed here: they are in `EVALUATION.md` (Quality standard v1) and `evals/model/thresholds.ts` and stay frozen (no case, threshold or rubric changes after a model has run without a logged re-freeze).

**Finished (Preview)** = gates G0 to G7 all pass, with the evidence listed, on Preview / clicky-dev. **Customer-ready** = also G8 (owner decisions). Nothing here touches `main` or Production.

Status words: *passed* (evidence attached), *failed* (evidence attached, fix in progress), *blocked* (cannot be run here, reason named), *not built*. A gate is never marked passed on a stand-in, a mock model or a fixture alone.

## Failure classification (required in every report)
Every failure is labelled **provider** (Groq unavailable, rate-limited, refused, a model that cannot honour the schema) or **agent** (our prompts, schemas, grounding, orchestration, UI). Provider failures are retried or worked around inside the existing adapter (shorter outputs, token pacing, `GROQ_STRICT`); agent failures are fixed in code with a test that reproduces them. A provider failure is never closed by weakening a check.

## Gates

|---|---|---|---|
| **G0** | Build health | `pnpm lint && pnpm typecheck && pnpm test && pnpm test:db && pnpm build` pass on the branch. | Command output. |
| **G1** | Model connection (§15) | With `MARKETING_MODEL_PROVIDER=groq`, key, model and `GROQ_PRICE_*` set: every agent schema (`business-understanding`, `marketing-analysis-model`, `marketing-strategy`, `content-creation` incl. campaign drafts) is accepted by Groq in the configured mode and returns valid, schema-conforming JSON in at least 19 of 20 calls each; a call that is rate-limited, refused or invalid ends in a plain recorded outcome. | **G2** | Understand a business (§3, §5) | On 3-5 real sites we own or may scan, the agent reads the site, proposes a Business Profile (what it sells, audience, positioning, trust signals, unknowns stated as unknown) and the owner can confirm, correct or reject each detail. Meets the *Understanding* and *Invented facts* lines of Quality standard v1. | Per-site review table checked against the live site. |
| **G3** | Research (§4) | The Research step uses only sources that exist: the site itself, competitor homepages the owner names, and owner-supplied Semrush or Search Console exports. It states what it did not and could not research (no competitor discovery, no live search data) and never invents competitors, rankings or traffic. The model summarises competitive context from the scanned signals and imported data, labelled inferred or estimated, each point citing its source. | A research result per site with sources; the "what we did not research" line present. |
| **G4** | Strategy (§7) | A business-specific strategy (objectives, positioning, audience, channel choice, priorities with reasons, what to leave for later) built from G2 and G3. Priorities point at real open Action Cards; no promise or figure outside the material; owner can revise with a note and approve. Meets the *Plan* line. | Stored plan per site, read against the evidence. |
| **G5** | Marketing plan (§7.2, §9) | The plan is a prioritised, dependency-ordered list of actions with effort and reason; campaigns have brief, tasks, channel, schedule and dependencies; a task cannot be done before what it depends on. | Plan and campaign records; the dependency test. |
| **G6** | Create content (§8) | Drafts for: homepage headline and supporting copy, SEO title and description, and campaign pieces (page, email, social post, Google post, text). Each is business-specific, uses only owner-given or confirmed facts, has version history, and meets the *Drafts* line (>= 80% usable with light edits, 0 invented claims). Content types in spec section 8 that are not built are listed by name as **not built**; they are not claimed. | Drafts per site with a read-through verdict; list of unbuilt types. |
| **G7** | Execute approved work and measure (§10, §11) | The full chain works end to end for the supported actions (`save_to_workspace`, `record_completed`): draft -> owner approves a version -> owner authorizes -> carried out -> verified by a later check, five separately recorded events, enforced server-side; a member cannot approve or authorize; duplicates are refused. Performance History accepts supplied figures, compares only adjacent equal periods, never attributes a change to work, and the next recommendations change when a result is recorded. Publishing, sending, social scheduling and ad spend stay **unsupported** (no authorized integration) and are shown as such, never run. | Browser test run on clicky-dev; execution records; a before/after recommendation pair. |

(b) Privacy Policy and Terms wording about model use reviewed by the owner and attorney before any customer data reaches a model. (c) OpenRouter stays off unless the owner approves after per-host privacy verification. (d) Production migrations applied only with explicit approval. | Owner sign-off. |

## Whole-workflow acceptance (the headline test)
On each of 3-5 real sites, one signed-in owner completes, on a phone-size screen without help: **website -> understanding -> research -> strategy -> plan -> drafts -> approve a draft -> authorize and record execution -> record a result -> see a changed recommendation.** The run is recorded in `marketing_workflows`, stays inside the cost and time lines of Quality standard v1 (<= $0.35 model spend and <= 100 s website check per business, or the documented background-job limits), and the frozen evaluation (`pnpm modelcheck` then `pnpm modelscore`, dev set then test set) is run and its real scores reported. The agent is **validated** only on two consecutive passing rounds, as in `EVALUATION.md`; a single pass is reported as "first round passed".

## Status against the specification (Nov 28 2026)
Implemented without a model and tested on fixtures: website intelligence, SEO checks, ranking, Action Cards, approvals, evidence classes, rules-based plan, campaign playbooks, execution records, performance comparison, request routing, metering, background jobs.

**Run on a real model (Groq free tier, `openai/gpt-oss-120b`) on Nov 28 2026:** all ten real agent schemas (understanding, findings, strategy plan, meta and page copy, and the five campaign channels) were accepted by Groq's strict structured-output mode; the frozen **dev set** (4 fictional cases, 20 tasks) ran with 20/20 usable, 95% on the first attempt, 90.6% of proposed items surviving our grounding checks. See `docs/agents/GROQ_FREE_TIER.md` and the report for the numbers and what they do not show. **The official test-set round and every human-scored criterion are not done**: they need a person (blind sheet) and more than one free daily allowance.

Built in this pass:
1. **Competitor discovery** (G3): `modules/competitor-discovery.ts`. OpenStreetMap and web-search candidates, each with its sources, evidence class "inferred", attribution and honest limits; saves nothing until the owner picks which to compare. Verified live: web search works; Overpass is unreachable from the cloud sandbox (connection reset), so the map source is verified only against stand-ins there. Summary of what was read: `modules/research-summary.ts` (grounded, cited, fixed "not researched" text).
2. **Conflicting-fact detection** (spec §14): `modules/fact-conflicts.ts`, panel on /app/business, disputed details flagged in prompts. Unit-tested on fixtures; no model involved.
3. **Content breadth** (spec §8): FAQ, article and brief as campaign channels (migration 20261206, applied to clicky-dev), with the same content checks. Homepage copy, SEO title and description, service/landing page, email, social, Google post and text message already existed. Not built: email *sequences*, lead magnets, ad copy, press releases (list them as **not built**; none is claimed).
4. **Publishing and sending** remain unsupported by design.

Still open: the official test-set evaluation and human scoring (two consecutive passing rounds); permission for more real sites (only somethingclicks.com is documented as ours); Production decisions (G8).
